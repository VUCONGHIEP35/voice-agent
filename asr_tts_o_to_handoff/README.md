# Cách mở trong VS Code
1. Cài tiện ích Claude Code (VS Code ≥ 1.94, tài khoản Claude trả phí hoặc Console).
2. Giải nén thư mục này, trong VS Code chọn File > Open Folder. Claude Code tự đọc CLAUDE.md ở gốc thư mục.
3. Mở panel Claude Code và gõ: "Đọc CLAUDE.md rồi làm tiếp: sinh 10.000 câu theo mô tả trong mục Việc cần làm. Kiểm tra luutru/generator/ trước, đừng tin nó khi chưa chạy."
